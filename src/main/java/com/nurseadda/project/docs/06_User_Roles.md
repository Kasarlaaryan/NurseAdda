# User Roles & Permissions

## Super Admin

Responsibilities

- Manage entire system
- Create Admin users
- Manage roles
- View all reports
- Configure system settings

Permissions

- Full system access

---

## Admin

Responsibilities

- Verify healthcare professionals
- Manage clients
- Manage assignments
- Generate invoices

Permissions

- CRUD Staff
- CRUD Client
- Manage Assignments
- Attendance
- Reports

---

## Healthcare Professional (Staff)

Responsibilities

- Register
- Manage availability
- Accept assignments

Permissions

- View assignments
- View attendance

---

## Client

Responsibilities

- Create staffing requests
- View assigned staff
- Approve assignments

Permissions

- Create requests
- View invoices
- View reports
